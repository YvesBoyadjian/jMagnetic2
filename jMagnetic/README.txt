
This is the source code for the Java port of Niclas Karlsson's
Magnetic interpreter. To rebuild, you will need SUN Java Development Kit
version 1.4.2 at least, however a Java 5 or Java 6 JDK is highly
recommended. Java 1.4.2 support might be dropped with one of the
next relases.
