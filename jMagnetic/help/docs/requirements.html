System requirements

To run JMagnetic you need a virtual machine compatible to SUN's Java Runtime 1.4.2 or higher that is capable of running Java Swing applications. For running JMagnetic under Linux the SUN JRE is required, since the GNU Java implementation does not yet include a full support for Swing applications. A MIDI device (internal or external) is required for the Wonderland music.

JMagnetic was tested with the following configurations and should run in comparable setups:
