Quickstart

  • Make sure that your system meets the minimum requirements.
  • Install JMagnetic using the installer for your desired operating system.
  • Put the game files (Story files, graphic files,...) into the game files subdirectory of the JMagnetic installation folder. What you need for playing:

    • (1) the story files;
    (2) the graphics files (optional);
    (3) the title pictures and music (optional);
    (4) the hint files (optional);

    Please make sure that all files for a game share the same filename except for the extension, e.g. pawn.mag, pawn.gfx, pawn.mp3,...

  • Double click the JMagnetic2.jar or use the icons/links that are created during installation to launch JMagnetic.
  • Select the game you want to play. Use the commands save and restore to keep your game progress.
