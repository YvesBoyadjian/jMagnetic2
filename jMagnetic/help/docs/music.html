Music files

The Amiga versions of some of the games featured title music. JMagnetic supports these music as MP3 streams, which can be obtained from the Magnetic Scrolls Memorial web page. The music files should have the same name as the game file, except that the music files end in ".mp3".

Wonderland included a handful of music scores that are played during the game. JMagnetic supports these music scores by looking for a file with the same name as the story file, but with the extension ".snd". The music files can be obtained from the Magnetic Scrolls Memorial site.
